**Mac Cleaner is now Floorspace, and it runs on macOS, Windows and Linux.**

See what's filling your disk and clear it safely: smart cleanup, a WizTree-style Disk Explorer, and an app uninstaller that also removes leftovers.

> [!WARNING]
> Floorspace is vibe-coded software that deletes files, written by Claude Opus 5.5 with a person steering. Everything goes to the Trash / Recycle Bin first, but **back up before cleaning**, and read the [disclaimer](https://github.com/EvanMeyer36/floorspace#vibe-coded-disclaimer). The Windows and Linux versions have only been tested by automated checks so far, so reports from real use are very welcome.

| **Windows 10/11** (x64) | `Floorspace-2.0.0-windows-setup.exe` or `…-windows.msi` | `Floorspace-2.0.0-windows-portable.zip`: unzip and run `Floorspace.exe` |
| **Linux** (x86_64) | `Floorspace-2.0.0-linux-amd64.deb` (Debian/Ubuntu), `…-linux-x86_64.rpm` (Fedora/openSUSE) | `Floorspace-2.0.0-linux-x86_64-portable.AppImage`: `chmod +x` and run |

**First launch.** The downloads aren't code-signed by Apple or Microsoft yet, so the system warns once:

- **macOS:** click **Done**, then **System Settings → Privacy & Security → Open Anyway**. Or run `xattr -dr com.apple.quarantine /Applications/Floorspace.app`.
- **Windows:** SmartScreen says the app is unrecognized. Choose **More info → Run anyway**.

Checksums are in `SHA256SUMS.txt`.

## What's new in 2.0

- **New name:** Floorspace. The old `mac-cleaner` links redirect here.
- **Windows and Linux:** a new desktop app with the same features. Smart Scan, cleanup categories with per-OS rules, the Disk Explorer, and app uninstall:
  - **Windows:** the program's own uninstaller, plus Store apps.
  - **Linux:** Flatpak, Snap, AppImage and distro packages.
- **One engine everywhere:** the native Mac app now runs on the same Rust engine as the desktop app, so cleanup rules, safety checks and fixes are shared across all three systems.
- **`floorspace` command-line tool:** `scan`, `junk`, `apps` and `trash`, with `--json` output (build from source).
- **Safety fixes found in review:**
  - archives are no longer pre-selected as "safe"
  - caches of open apps aren't pre-selected
  - scans skip other mounted drives
  - uninstalling App Store apps no longer risks a crash
- **Disk Explorer:**
  - faster hovering on big maps
  - layout waits until window resizing pauses
  - in the desktop app, the folder tree keeps folders open after removing something
